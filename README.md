# DesignVault Demo

DesignVault is a front-end demo for a creative design marketplace with support for free/premium designs and Urdu/Punjabi content.

## Run locally
Open `index.html` in a modern browser.

## Deploy with GitHub Pages
1. Create a public GitHub repository named `designvault`.
2. Upload `index.html`, `style.css`, and `app.js`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait a few minutes. Your site will be available at:
   `https://YOUR-USERNAME.github.io/designvault/`

## Important
This is a static demo. Upload, purchase and download interactions are simulated. Do not put passwords, API keys, payment secrets, or private credentials into these files.

For the production marketplace, add a secure backend, authentication, database, private file storage, malware scanning, server-side validation, payment processing, authorization checks, rate limiting, audit logs, backups, copyright/takedown workflows and security testing.
